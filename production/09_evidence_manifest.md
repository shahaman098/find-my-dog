## Disclosures

- **Recording environment:** local Worker (`wrangler dev`, real mode) running this commit against the live Meta API, because the production deploy was not available in time. SAM receives clips via the Meta Files API in this environment (worker/src/meta.ts `uploadVideo`, used when the clip URL is not public).
- **Pointer:** headless automation does not move the OS cursor, so a small on-page ring follows the real input events (production/capture_prod.cjs `POINTER`).
- **Footage licence:** both clips are Internet Archive items with no stated licence; every person and number plate is pixelated.
- **Reference photo:** a crop from the same dog-park footage (easier than a real owner photo; see EVIDENCE.md §8).
- **Terminal panels:** recorded sessions (production/term_record.cjs) replayed at recorded speed; commands are printed exactly as executed.
- **Music:** original procedural score (production/score.py); no third-party audio.
- **Generated imagery:** the poster is generated by Muse Image inside the product. Film 3 uses Muse Image concept stills, each marked "concept imagery".
